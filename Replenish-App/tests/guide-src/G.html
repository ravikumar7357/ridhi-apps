Fabric Inventory — greige → RFD → cutting · फैब्रिक इन्वेंटरी — ग्रे → RFD → कटिंग

1. Greige PO→2. Mail→3. Greige received→4. Sent for RFD→5. RFD received→6. Issued to cutting
Every metre is followed lot by lot. A lot is one delivery from the mill. The lot number stays with the cloth at every step, so you can always see how much is still greige, how much is with the processor, how much came back as RFD, and how much was lost.
हर मीटर का हिसाब लॉट के हिसाब से रहता है। मिल से आई एक डिलीवरी = एक लॉट। लॉट नंबर हर स्टेप पर कपड़े के साथ चलता है — जिससे पता रहता है कि कितना अभी ग्रे है, कितना प्रोसेसर के पास है, कितना RFD बनकर वापस आया और कितना कम हुआ।
Greige name vs RFD name. Greige is bought wider than the RFD it becomes. The Sheeting 62 on the cutting table is bought as Greige Sheeting 67. The PO and the mill see the greige name; when it comes back from the processor, the app records it as Sheeting 62 by itself.
ग्रे का नाम और RFD का नाम अलग है। ग्रे चौड़ा आता है, प्रोसेस के बाद चौड़ाई कम होती है। कटिंग वाला Sheeting 62 मिल से Greige Sheeting 67 नाम से खरीदा जाता है। PO पर ग्रे का नाम जाता है; प्रोसेसर से वापस आने पर ऐप अपने आप उसे Sheeting 62 लिख देता है।
AOne-time setup · एक बार की सेटिंग
  • Masters → Fabric type: type the Greige name next to each RFD fabric (or use Excel template → fill → Excel import). One greige name belongs to one fabric only. Admins only.
  • Vendor Orders → Vendors: set Kind = Mill for greige suppliers and Processor for the RFD house. Add each mill's email.
  • Fabric Inventory → view "Greige POs" → PO settings (admin): company name, address, GSTIN, phone, email and default terms for the top of every PO.
  • Masters → Fabric type: हर RFD फैब्रिक के सामने Greige name लिखें (या Excel template → भरें → Excel import)। एक ग्रे नाम सिर्फ एक फैब्रिक का। सिर्फ एडमिन।
  • Vendor Orders → Vendors: ग्रे देने वाले के लिए Kind = Mill, RFD करने वाले के लिए Processor। मिल का ईमेल ज़रूर भरें।
  • Fabric Inventory → "Greige POs" → PO settings (एडमिन): कंपनी का नाम, पता, GSTIN, फोन, ईमेल और शर्तें — ये हर PO के ऊपर छपती हैं।
0RFD opening stock (once, at the start) · RFD ओपनिंग स्टॉक (शुरू में एक बार)
For RFD cloth already on the floor: + Fabric entry → "RFD opening stock (already on the floor)" — fabric, metres, date. Leave Lot empty and one is made; write it on the bale. For many fabrics at once: Template → fill rows with Movement = RFD opening stock → Bulk upload. It shows in its own RFD opening column and never counts as processing loss. Cutting is then issued from that lot as usual.
जो RFD कपड़ा अभी फ्लोर पर पड़ा है उसके लिए: + Fabric entry → "RFD opening stock (already on the floor)" — फैब्रिक, मीटर, तारीख। Lot खाली छोड़ें, नंबर अपने आप बनेगा; वही गठ्ठर पर लिखें। कई फैब्रिक एक साथ: Template → लाइनें भरें, Movement = RFD opening stock → Bulk upload। यह अलग RFD opening कॉलम में दिखेगा और प्रोसेस लॉस में नहीं गिना जाएगा। फिर उसी लॉट से कटिंग को दें।
1Raise the greige PO · ग्रे का PO बनाएँ
Fabric Inventory → view "Greige POs" → + Greige PO
  • Pick the mill, PO date and deliver-by date.
  • Each line: pick the RFD fabric — the greige name fills in by itself.
  • Enter metres, rate per metre and GST % (5 by default).
  • Press Raise PO. Number: GPO-YYMMDD-01, -02…
  • Edit or cancel only until cloth arrives. Cancelling needs a reason.
Fabric Inventory → "Greige POs" → + Greige PO
  • मिल, PO तारीख और डिलीवरी की तारीख चुनें।
  • हर लाइन में RFD फैब्रिक चुनें — ग्रे नाम अपने आप आ जाएगा।
  • मीटर, रेट (प्रति मीटर) और GST % भरें (पहले से 5)।
  • Raise PO दबाएँ। नंबर अपने आप बनेगा: GPO-YYMMDD-01, -02…
  • माल आने से पहले तक ही Edit या Cancel। Cancel में कारण लिखना ज़रूरी है।
2Print or mail it · प्रिंट करें या मेल भेजें
  • Print opens the PO page → Print / Save as PDF.
  • Mail sends the PO as a PDF attachment from ravi@thefabricrush.com to the mill. Add Cc and a message if needed. The row then shows "mailed 1×".
Limits: greige POs only, 5 addresses per mail, 40 a day. Mail works for admins; others use Print → Save as PDF.
  • Print से PO खुलता है → Print / Save as PDF।
  • Mail से PO की PDF ravi@thefabricrush.com से मिल को चली जाती है। चाहें तो Cc और मैसेज जोड़ें। फिर लाइन में "mailed 1×" दिखेगा।
सीमा: सिर्फ ग्रे PO, एक मेल में 5 पते, दिन में 40। मेल एडमिन भेज सकते हैं; बाकी लोग Print → Save as PDF करके भेजें।
3Greige arrives · मिल से ग्रे आया
Greige POs → Receive on that PO. The form opens filled with the greige name, metres still to come, mill and PO number.
  • Type the metres that actually arrived. Part deliveries are fine — the PO shows "Part received".
  • Lot: the mill's lot no., or leave blank and one is made. Write it on the bale.
  • Add bill / challan no. and rate.
उसी PO पर Receive दबाएँ। फॉर्म में ग्रे नाम, बाकी मीटर, मिल और PO नंबर पहले से भरे मिलेंगे।
  • जितने मीटर असल में आए वही लिखें। थोड़ा-थोड़ा माल आए तो भी ठीक — PO पर "Part received" दिखेगा।
  • Lot: मिल का लॉट नंबर लिखें, या खाली छोड़ें — नंबर अपने आप बनेगा। यही नंबर गठ्ठर पर लिखें।
  • बिल / चालान नंबर और रेट भरें।
4Send greige for RFD · ग्रे को RFD के लिए भेजें
Fabric Inventory → + Fabric entry → "Greige sent for RFD processing"
  • Type the fabric (greige or RFD name, both work), then pick the lot — it shows how much is left.
  • Enter metres and who is processing it.
  • You cannot send more than the lot holds.
Fabric Inventory → + Fabric entry → "Greige sent for RFD processing"
  • फैब्रिक लिखें (ग्रे या RFD कोई भी नाम चलेगा), फिर लॉट चुनें — उसमें कितना बचा है दिखेगा।
  • मीटर और प्रोसेसर का नाम भरें।
  • लॉट में जितना है उससे ज़्यादा नहीं भेज सकते।
5RFD comes back · RFD वापस आया
+ Fabric entry → "RFD received back"
  • Pick the same lot and enter the metres that came back.
  • It is recorded under the RFD name (Greige Sheeting 67 → Sheeting 62).
  • Cannot be more than is with the processor.
  • The lot's loss % is worked out (600 sent, 570 back = 5%).
+ Fabric entry → "RFD received back"
  • वही लॉट चुनें और जितने मीटर वापस आए वो भरें।
  • ये RFD नाम से दर्ज होगा (Greige Sheeting 67 → Sheeting 62)।
  • प्रोसेसर के पास जितना है उससे ज़्यादा नहीं ले सकते।
  • लॉट का लॉस % अपने आप निकलेगा (600 भेजा, 570 आया = 5%)।
6Issue RFD to cutting · RFD कटिंग को दें
+ Fabric entry → "Issued to cutting". Type the RFD fabric (Sheeting 62), pick the lot, enter metres. Never more than the lot holds.
+ Fabric entry → "Issued to cutting"। RFD फैब्रिक (Sheeting 62) लिखें, लॉट चुनें, मीटर भरें। लॉट से ज़्यादा नहीं दे सकते।
7Where to see everything · सब कहाँ देखें
The first drop-down on Fabric Inventory picks the view:
  • Stock balance — balance per fabric, colour and state (Greige / RFD / Printed).
  • Greige → RFD → cutting — per fabric: greige in, with processor, RFD back, issued to cutting.
  • Lots — bale by bale — per lot: bill, mill, processor, greige left, RFD left, loss %.
  • Every movement — the full ledger.
  • Greige POs — every PO: ordered / received / to come, amount, stage.
Template and Bulk upload enter many movements at once from a sheet.
Fabric Inventory का पहला ड्रॉप-डाउन व्यू चुनता है:
  • Stock balance — फैब्रिक, रंग और स्टेट (ग्रे / RFD / प्रिंटेड) के हिसाब से बैलेंस।
  • Greige → RFD → cutting — हर फैब्रिक: ग्रे आया, प्रोसेसर के पास, RFD वापस, कटिंग को गया।
  • Lots — bale by bale — हर लॉट: बिल, मिल, प्रोसेसर, बचा ग्रे, बचा RFD, लॉस %।
  • Every movement — पूरी एंट्री लिस्ट।
  • Greige POs — हर PO: ऑर्डर / आया / बाकी, रकम, स्टेज।
Template और Bulk upload से शीट से एक साथ कई एंट्री कर सकते हैं।
Good to know. The app refuses: a PO for a fabric with no greige name; receiving a different cloth against a PO; a wrong or cancelled PO; sending more than a lot holds; receiving more RFD than is with the processor; cancelling a PO that has cloth against it. Raising, receiving and mailing POs needs the right to edit production entries; Masters and PO settings are admin only.
ध्यान दें। ऐप इन्हें रोकता है: बिना ग्रे नाम वाले फैब्रिक का PO; PO में अलग कपड़ा receive करना; गलत या कैंसल PO; लॉट से ज़्यादा भेजना; प्रोसेसर के पास से ज़्यादा RFD लेना; माल आ चुके PO को कैंसल करना। PO बनाना, receive और मेल करना "production entries edit" वाले अधिकार से होता है; Masters और PO settings सिर्फ एडमिन।
