What to do with it
  1. Copy the code above (it is only good for a minute or two).
  2. Run the exchange command on your own computer — it needs the app's secret, which must never be typed into a web page.
  3. The answer contains access_token, starting shpat_. That is the permanent token; put it straight into Script Properties.
