Weights are worked out, not typed: net is qty × per-piece weight added up, gross is net plus the packing weight, volume weight is L×W×H ÷ the divisor. Type a gross weight only where you have actually put the box on a scale.
Per SKU — description, size, weight
Everything here is a fact about the PRODUCT, not about the box, so it is edited once per SKU and applies to every box it appears in — and is remembered for every packing list after this one. Description and size fill in from the catalogue; a SKU the catalogue has never heard of falls back to its own code (shown yellow) and that code is what would print on the label.
