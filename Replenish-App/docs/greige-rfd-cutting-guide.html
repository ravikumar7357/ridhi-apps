Greige → RFD → Cutting

Step-by-step guide for the Replenishment app (fabricrush-replenish.web.app) · The Fabric Rush · September 2026
1. Greige PO→2. Mail to mill→3. Greige received→ 4. Sent for RFD→5. RFD received→6. Issued to cutting

Every metre is followed lot by lot. A lot is one delivery from the mill. The same lot number travels with the cloth at every step, so you can always see how much of a delivery is still greige, how much is with the processor, how much came back as RFD, and how much was lost in processing.

Greige name vs RFD name. Greige is bought wider than the RFD it becomes. Example: the Sheeting 62 used on the cutting table is bought as Greige Sheeting 67. The PO and the mill see the greige name. When the cloth comes back from the processor, the app records it as Sheeting 62 automatically.

One-time setup (do this once)

AGreige name for each fabric
Masters → Fabric type → column Greige name (what the mill is sent).
Type the greige name next to each RFD fabric, e.g. Sheeting 62 → Greige Sheeting 67. It saves the moment you leave the box.
  • A fabric with no greige name cannot go on a greige PO.
  • One greige name can belong to only one fabric (otherwise the app would not know what it becomes).
  • Only an admin can change Masters.
Har RFD fabric ke saamne uska greige naam likh do.
BMills and processors in the vendor list
Vendor Orders → Vendors. Set Kind = Mill for greige suppliers, and Processor for the RFD processing house. Add each mill's email, because the PO is mailed there.
Mill ka email zaroor bharo, PO wahi jayega.
CCompany details on the PO
Fabric Inventory → view "Greige POs" → PO settings (admin only).
Fill in company name, address, GSTIN, phone, email and default terms. These are printed at the top of every PO.

The daily flow

1Raise the greige PO
Fabric Inventory → view "Greige POs" → + Greige PO
  • Pick the mill, the PO date and the deliver-by date.
  • On each line pick the RFD fabric you need (e.g. Sheeting 62). The greige name fills in by itself.
  • Enter metres, rate per metre and GST % (5 is filled in; change it if needed).
  • Add terms or remarks if this PO needs something different from the default.
  • Press Raise PO. The number is made for you: GPO-YYMMDD-01, then -02 and so on for that day.
Tip: a PO can be edited or cancelled until cloth has come in against it. Cancelling asks for a reason.
2Print or mail it to the mill
On the PO's row:
  • Print opens the PO as a page. Press Print / Save as PDF to print it or keep a PDF copy.
  • Mail sends the PO as a PDF attachment from ravi@thefabricrush.com to the mill's email. You can add Cc and a short message. The row then shows "mailed 1×". Use Mail again if needed.
Mail limits: only greige POs can be sent this way, at most 5 addresses per mail and 40 PO mails a day. Mail needs access to the app's backend, which admins have. If you cannot mail, use Print → Save as PDF and send it yourself.
3Greige arrives from the mill
Greige POs → Receive on that PO. The entry form opens already filled with the greige name, the metres still to come, the mill and the PO number.
  • Type the metres that actually arrived. Part deliveries are fine; the PO shows "Part received" and how much is still to come.
  • Lot: type the mill's lot number, or leave it blank and one is made (e.g. GREIGE-SHEETING-67-260925-01). Write it on the bale.
  • Add the bill / challan number and the rate.
Received wahi maana jayega jo is PO number ke against entry hui hai.
4Send the greige for RFD processing
Fabric Inventory → + Fabric entry → "Greige sent for RFD processing"
  • Type the fabric (greige name or RFD name, both work), then pick the lot. The list shows how much greige is left in each lot.
  • Enter the metres and who is processing it (the processor).
  • You cannot send more than is left in that lot.
5RFD comes back from the processor
+ Fabric entry → "RFD received back"
  • Pick the same lot and enter the metres that came back.
  • The app records it under the RFD fabric name (Greige Sheeting 67 comes back as Sheeting 62), using the greige name set in Masters.
  • You cannot receive more than is still with that processor.
  • The loss % for the lot is worked out by itself (e.g. 600 m sent, 570 m back = 5% loss).
6Issue RFD to cutting
+ Fabric entry → "Issued to cutting"
  • Type the RFD fabric (e.g. Sheeting 62), pick the lot, and enter the metres.
  • You cannot issue more RFD than the lot holds.

After cutting: cloth for the printers (RFD Requirements)

7Printers ask for cloth; the office sends it
  • Each printer opens their own portal → RFD, picks an order, and fills With you with what they already have for that order. The number comes off what is left to ask for on that order only.
  • They ask size by size, or use Ask for the whole order…, which asks them to confirm first.
  • Anything inside what the order covers is agreed at once. Anything beyond it waits for approval in RFD Requirements.
  • In RFD Requirements each row shows asked − with them = to send. Press Mark sent to record what went out; it cannot go over the to-send figure.
  • To refuse several at once, tick them and press Refuse ticked with one reason. The printer sees the reason.

Checks the app does for you

If you try to…The app says
Put a fabric with no greige name on a POAdd its greige name in Masters → Fabric type first.
Receive a different cloth against a PO"GPO-… is for Greige Sheeting 67 — not …"
Receive against a PO that does not exist, or was cancelledRefused, with the reason.
Send more greige for RFD than the lot holdsOnly what is left in the lot can go.
Receive more RFD than is with the processorRefused. It is someone else's cloth or a typo.
Cancel a PO that already has cloth against itNot allowed.
Mail a PO to a wrong addressEvery address is checked before anything is sent.
Who can do what. Raising, receiving and mailing POs needs the right to edit production entries. Masters and PO settings are admin only. Anyone with the Fabric Inventory tab can see the POs.
